# Adventures in cline but so interesting

Платформер в одном HTML-файле. Полностью свободный: лицензия **GNU GPL v3 (или новее)**.

- 80 уровней и босс на 81-м (с пружинами, взрывными бочками и падающими камнями на арене)
- Режимы: **Обычный**, **Свободный**, **На время**, **Аркада**, **Сладкий** (бесконечный), **Мультиплеер** (2–4 игрока на одном экране), **Дуэль** 1 на 1
- **Мастерская**: редактор карт (земля, платформы, шипы, враги, монеты, пружины, гейзеры, старт и финиш), сохранение, числовые ID карт (1, 2, 3…) и обмен картами числовым кодом
- Магазин фонов и скинов, достижения, промокоды, встроенный терминал (`help`)
- Установка как приложение (PWA), сборки для Linux (AppImage) и Android (APK)

## Мастерская: ID и коды карт

- Каждая сохранённая карта получает **числовой ID** на этом устройстве: 1, 2, 3… (номера не повторяются).
- Свою карту можно запустить по ID: в Терминале `master load 3`.
- Чтобы поделиться, нажми 📤 у карты, получишь **числовой код** (одно длинное число, оно содержит саму карту). Друг вводит его в «Импорт» или командой `master load <число>`; карта сохранится у него под новым ID.
- Короткие ID, общие для всех устройств, потребовали бы сервера. В проекте его нет, поэтому для чужих карт используется самодостаточный числовой код.

## Команды Терминала

`help`, `play [режим]`, `custom`, `fastfetch`, `promokod "код"`, `achievement`, `license`, `master`, `master create`, `master load [ID или код]`, `clear`, `exit`.
(Есть и скрытые команды, найди их в исходнике.)

## Запуск

Просто открой `index.html` в современном браузере. Ничего собирать не нужно.

Для установки как приложение (PWA) **все файлы** нужно раздать по **https** (или `localhost`): Netlify Drop, GitHub Pages (`pages.yml`), Cloudflare Pages
или `python3 -m http.server`. Без этого Chrome не покажет кнопку «Установить». Подробно: [`docs/HOSTING.md`](docs/HOSTING.md).

## Управление

| Игрок | Движение | Прыжок | Огонь (дуэль) |
|-------|----------|--------|---------------|
| 1 | A / D | W | F |
| 2 | ← / → | ↑ | Enter |
| 3 | J / L | I | |
| 4 | 4 / 6 | 8 | |

Раскладка клавиатуры не важна (используются физические клавиши). На телефоне есть экранные кнопки, играть нужно в горизонтальной ориентации.

## Сборка пакетов

См. [`docs/BUILD.md`](docs/BUILD.md). Коротко:

```bash
cd desktop && npm install && npm run dist        # -> desktop/dist/*.AppImage
cd android && npm install && node scripts/prepare.js && npx cap add android && node scripts/patch-android.js \
  && npx cap sync android && cd android && ./gradlew assembleDebug
```

> Конфигурация AppImage/APK написана, но **не запускалась** в среде, где создавался архив (нет сети и Android SDK).
> Поэтому первая сборка может потребовать мелких правок. Проще всего запустить workflow `build-packages` в GitHub Actions.
